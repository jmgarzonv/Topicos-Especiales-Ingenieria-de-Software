Recibe un número entero desde la URL y muestra su factorial en una página web.

* Como ejecutar?
1. Clona el repositorio 
2. Abre una terminal y navega al directorio del proyecto:

```bash
cd flask_factorial
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

Ejecuta la aplicación:
```bash
python app.py
```

ir a la ruta
```bash 
http://127.0.0.1:5000/factorial/5
```

se puede cambiar el 5  por cualquier entero positivo para ver su factorial.
